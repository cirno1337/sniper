# Źródła grafik — Rozdział 5 (Employment)

Rozdział 5 jest niemal wyłącznie doktrynalny/taktyczny — oryginalny podręcznik
nie zawiera żadnych rysunków technicznych w tym rozdziale poza Figure 5-1
(wzór rozkazu operacyjnego snajpera), który został przepisany jako natywna
lista markdown w treści lekcji zamiast jako obraz. Table 5-1 (tabela azymutu
wschodu/zachodu słońca dla różnych szerokości geograficznych) jest opisana
tekstowo bez reprodukcji pełnych danych liczbowych — niska wartość
dydaktyczna do zapamiętania, a oryginał liczy dwie pełne strony surowych liczb.
